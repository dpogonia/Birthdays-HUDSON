# Birthdays

Список дней рождения. Проект в Xcode по-прежнему называется Weather Now.

## Что умеет приложение

В списке имя и дата. Если день рождения сегодня, рядом торт. Снизу поле имени, выбор даты и кнопка Save. Записи хранятся на устройстве.

## Стек

SwiftUI, SwiftData.

## Запуск

```bash
git clone https://github.com/dpogonia/Birthdays.git
cd Birthdays
open "Weather Now.xcodeproj"
```

Запустите схему **Weather Now** на симуляторе iPhone.
