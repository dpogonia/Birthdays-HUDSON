# Birthdays

A birthday list. The Xcode project is still named Weather Now.

## What it does

The list shows a name and a date. A cake appears next to a birthday that is today. The bottom has a name field, a date picker, and a Save button. The entries stay on the device.

## Stack

SwiftUI, SwiftData.

## Run

```bash
git clone https://github.com/dpogonia/Birthdays.git
cd Birthdays
open "Weather Now.xcodeproj"
```

Run the **Weather Now** scheme on an iPhone simulator.
